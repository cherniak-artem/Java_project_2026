# Контрольні питання
## 1. В чому полягає різниця між ключовими та зарезервованими словами?

Ключові слова (keywords) - це слова, які мають спеціальне значення в мові Java і не можуть використовуватися як імена змінних, методів або класів. Наприклад: class, int, if, else, return, static.

Зарезервовані слова - це слова, які зарезервовані мовою Java для можливого використання в майбутньому, але наразі не мають звичайного практичного застосування. Наприклад, goto та const.

## 2. Які примітивні типи даних Ви знаєте?

У Java є 8 примітивних типів:

|Тип|Розмір|Приклад використання| 
|:----------:|:-------------:|---------|
|byte| 8 біт|Невеликі числові значення, наприклад кількість символів або дані невеликого діапазону|
|short| 16 біт|Невеликі цілі числа, наприклад кількість місць у великій системі|
|int| 32 біти|Найчастіше використовується для цілих чисел: рахунок у футбольному матчі, кількість предметів|
|long| 64 біти|Дуже великі цілі числа: кількість мілісекунд, великі розміри файлів у байтах|
|float| 32 біти|Дробові числа, коли не потрібна висока точність: приблизні фізичні вимірювання|
|double| 64 біти|Дробові числа, коли потрібна більша точність: наукові та інженерні розрахунки|
|char| 16 біт|Один символ: 'A', 'Б', '7'|
|boolean|	— 	|Логічні значення: true або false, наприклад відповідь на питання «чи увімкнений пристрій?»

## 3. Що таке знакові та беззнакові типи?

Знаковий тип може зберігати як додатні, так і від'ємні числа.

У Java знаковими є:

|byte|short|int|long|float|double|
|---|---|---|---|---|---|

* char у Java є беззнаковим цілочисельним типом і може мати значення від 0 до 65535.
* boolean не є числовим типом і приймає лише true або false.

## 4. Яке максимальне число можна записати у змінну типу short, char, int, long?
|Тип|Максимальне значення|
|:---:|---|
|short|32 767|
|char|65 535|
|int|2 147 483 647|
|long|9 223 372 036 854 775 807|

Для знакових цілих типів максимальне значення обчислюється як:

$$ 2^{n-1}-1 $$

де \(n\) - кількість бітів.

Для char:

$$ 2^{16} − 1 = 65535 $$

## 5. Чому byte має діапазон -128..127?

byte займає 8 бітів.

Оскільки він знаковий, один біт використовується для представлення знака, а фактичний діапазон у доповняльному коді становить:

$$ -2^7 \ldots 2^7-1 $$

$$ {-128\ldots127} $$

Від'ємних значень на одне більше, тому що в доповняльному коді існує окреме представлення числа -128, але додатного +128 вже немає.

Усього маємо 256 різних комбінацій:

$$ 2^8=256 $$

від -128 до 127 включно також є рівно 256 значень.

## 6. Що таке система числення? Як переводити значення з однієї системи числення в іншу?

Система числення - це спосіб запису чисел за допомогою певного набору цифр та правил їх використання.

Основні системи:

* двійкова - основа 2: 0, 1;
* вісімкова - основа 8: 0–7;
* десяткова - основа 10: 0–9;
* шістнадцяткова - основа 16: 0–9, A–F.

Наприклад, двійкове число 1011₂ переводимо в десяткову систему:

$$ 1011_2=1\cdot2^3+0\cdot2^2+1\cdot2^1+1\cdot2^0=8+0+2+1=11_{10} $$

Для переведення десяткового цілого числа в іншу систему зазвичай використовують послідовне ділення на основу системи числення та записують остачі у зворотному порядку.

## 7. Що таке «Доповняльний код»?

Доповняльний код - це спосіб представлення від'ємних цілих чисел у двійковій системі.

Щоб отримати доповняльний код від'ємного числа:

Записують двійкове представлення додатного числа.
Інвертують усі біти.
Додають 1.

Наприклад, для -5 у 8-бітному представленні:
5 = 00000101

Інвертуємо:

$$ 11111010 $$

Додаємо 1:

$$ 11111011 $$

Отже:

$$ -5 = 11111011 $$

## 8. Пояснити результат роботи коду

    int a = 2_000_000_000;
    int b = 2_000_000_000;
    int c = a + b;
    
        System.out.println(c);

Тип int має максимальне значення:

$$ 2\,147\,483\,647 $$

А сума:

$$ 2\,000\,000\,000+2\,000\,000\,000=4\,000\,000\,000 $$

це більше за максимальне значення int.

Тому виникає переповнення (overflow). Java не видає помилку, а результат переходить через межу діапазону int.

Результат:

$$ -294967296 $$

## 9. Чим тип float відрізняється від double?

Обидва типи використовуються для представлення дробових чисел.

* float займає 32 біти;
* double займає 64 біти.

double має більшу точність і ширший діапазон значень.

Наприклад:

    float a = 3.14f;
    double b = 3.141592653589793;

У більшості математичних розрахунків у Java доцільно використовувати double, якщо немає спеціальної потреби в float.

## 10. Що таке число з рухомою комою? Що таке мантиса та степінь?

Число з рухомою комою - це спосіб представлення дуже великих або дуже малих дробових чисел за допомогою двох основних частин: мантиси та порядку (степеня).

Наприклад:

$$ 12345.6=1.23456\cdot10^4 $$

Тут:

* 1.23456 - мантиса;
* 4 - степінь (порядок);
* 10 - основа системи.

У Java типи float та double використовують представлення чисел із рухомою комою.

## 11. Що таке Double.NaN?

Double.NaN означає Not a Number - «не число».

Це спеціальне значення типу double, яке використовується для результатів невизначених математичних операцій.

Наприклад:

    double x = 0.0 / 0.0;
    System.out.println(x);

Результат: NaN

## 12. Пояснити результат
    
    System.out.println(Double.NaN == Double.NaN);

Результат:

    false

Це особливість стандарту IEEE 754, за яким NaN не дорівнює навіть самому собі.

Тому для перевірки використовується:

    Double.isNaN(value)

Наприклад:

    double x = Double.NaN;
    System.out.println(Double.isNaN(x));

Результат:

    true

## 13. Різниця між преінкрементом та постінкрементом

Преінкремент ++a спочатку збільшує значення змінної на 1, а потім повертає нове значення.

Постінкремент a++ спочатку повертає старе значення, а вже потім збільшує змінну на 1.

Наприклад:

    int a = 5;
    int b = ++a;

    System.out.println(a); // 6
    System.out.println(b); // 6

А при постінкременті:

    int a = 5;
    int b = a++;

    System.out.println(a); // 6
    System.out.println(b); // 5

Отже, різниця проявляється тоді, коли результат операції ++ використовується в іншому виразі.

## 14. Різниця між логічною та побітовою операцією AND

Логічний AND && працює з логічними значеннями boolean:

    true && true   // true
    true && false  // false

Він є короткозамкнутим: якщо перший операнд false, другий може взагалі не обчислюватися.

Побітовий AND & виконує операцію над окремими бітами чисел:

При роботі з boolean & також може використовуватися як логічний AND, але без короткого замикання.

Тому & може працювати і з цілими числами, і з boolean, а && — тільки з boolean.

## 15. В чому різниця між OR та XOR?

OR (|) повертає true, якщо хоча б один з операндів true.

|A|B|A OR B|
|:---:|:---:|:---:|
|false|false|false|
|false|true|true|
|true|false|true|
|true|true|true|

XOR (^) повертає true, якщо тільки один операнд true.

|A|B|A XOR B|
|:---:|:---:|:---:|
|false|false|false|
|false|true|true|
|true|false|true|
|true|true|false|

Отже, головна відмінність:

* OR — один або обидва;
* XOR — тільки один.

##16. Аналіз фрагмента програми

    boolean a = true && false | false;
    System.out.println(a = false);

    boolean b = true && false || false;
    System.out.println(b = true);

Спочатку обчислюється:

    boolean a = true && false | false;

У результаті:

    true && false -> false
    false | false -> false

Отже, a спочатку отримує false.

Але наступний рядок:

    System.out.println(a = false);

Це присвоєння, а не порівняння. Значенню a присвоюється false, і саме це значення виводиться.

Результат:

    false

Далі:

    boolean b = true && false || false;

Обчислення:

    true && false -> false
    false || false -> false

Отже:

    b = false

Але потім:

    System.out.println(b = true);

змінній b присвоюється true, і true виводиться на екран.

Загальний результат програми:

    false
    true

Важливо: у двох System.out.println() використовується оператор присвоєння =, тому попереднє значення змінних фактично замінюється.
