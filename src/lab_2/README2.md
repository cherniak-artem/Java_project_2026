# Контрольні питання

## 1. Що таке структурне програмування?

Структурне програмування - це підхід до розробки програмного забезпечення, за якого програма будується з окремих логічних блоків, що мають чітку структуру та послідовність виконання.

Основна мета структурного програмування - створення зрозумілого, логічного, надійного та зручного для супроводження коду.

## 2. Назвіть основні конструкції структурного програмування.

Виділяють три основні конструкції:

1. Послідовність - команди виконуються одна за одною в заданому порядку.
2. Розгалуження - вибір одного з варіантів виконання залежно від певної умови (if, if-else, switch).
3. Повторення (цикл) - багаторазове виконання певного блоку команд (for, while, do-while).

## 3. Назвіть основні принципи структурного програмування.

Основними принципами є:

- Використання трьох базових конструкцій: послідовності, розгалуження та циклу.
- Поділ складної програми на менші логічні частини (модулі та методи).
- Використання принципу проєктування зверху-вниз.
- Відмова від безумовних переходів між довільними ділянками програми (goto).
- Забезпечення зрозумілості, читабельності та простоти супроводження коду.
- Кожен логічний блок повинен виконувати конкретне завдання.

## 4. Поясніть, чому в більшості мов програмування не радять використовувати оператор GOTO, а в мові Java його взагалі немає?

Оператор GOTO забезпечує безумовний перехід до іншої ділянки програмного коду.
Його надмірне використання може призвести до ускладнення структури програми, оскільки послідовність виконання команд стає важкою для розуміння та відстеження.
Це ускладнює пошук помилок, тестування та подальше редагування програми.
У мові Java оператор goto є зарезервованим словом, але його використання не реалізоване. Замість нього застосовують структурні конструкції (if, switch, цикли), а також оператори break і continue.

## 5. Що таке спагеті-код?

Спагеті-код - це програмний код із заплутаною та нелогічною структурою, у якому важко простежити послідовність виконання команд.
Зазвичай він виникає через надмірне використання переходів, складних умов, вкладених конструкцій та відсутність поділу програми на логічні частини.
Такий тип коду важко читати, тестувати, виправляти та супроводжувати.

## 6. Що таке проєктування зверху-вниз? В чому його переваги?

Проєктування зверху-вниз (Top-Down Design) - це метод розробки програми, за якого спочатку визначають загальну задачу, а потім поступово розділяють її на менші підзадачі, поки кожна з них не стане достатньо простою для реалізації.

Наприклад, програму для обчислення середнього арифметичного можна розділити на такі завдання:
1. Отримання чисел.
2. Обчислення їхньої суми.
3. Обчислення середнього значення.
4. Виведення результату.

Переваги:
- Спрощує розробку складних програм.
- Дозволяє розділити роботу між кількома програмістами.
- Полегшує тестування та пошук помилок.
- Робить програму більш зрозумілою та структурованою.
- Спрощує подальше внесення змін.

## 7. Що таке область видимості ідентифікатора?

Область видимості ідентифікатора (Scope) - це частина програмного коду, у межах якої можна звертатися до певної змінної, методу або іншого ідентифікатора.
У Java область видимості залежить від місця оголошення ідентифікатора.

Наприклад:
- Локальні змінні доступні лише в межах методу або блоку, у якому їх оголошено.
- Параметри методу доступні всередині відповідного методу.
- Поля класу доступні відповідно до модифікаторів доступу та контексту звернення.

## 8. Що таке блок? Як блоки впливають на область видимості?

Блок - це група команд, обмежена фігурними дужками { }.
Блоки використовуються для об'єднання декількох команд в одну логічну конструкцію.
Вони також визначають область видимості локальних змінних.

## 9. Наведіть приклади, у яких випадках краще використовувати наступні оператори та конструкції.

1. if
Використовується, коли потрібно виконати певну команду лише за умови, що логічний вираз має значення true.
Приклад: перевірка, чи користувач досяг повноліття.

    int age = 20;

    if (age >= 18) {
    System.out.println("Повнолітній");
    }

2. if-else
Використовується, коли потрібно вибрати один із двох варіантів виконання програми.
Приклад: перевірка парності числа.

    int number = 7;
    
    if (number % 2 == 0) {
    System.out.println("Парне число");
    } else {
    System.out.println("Непарне число");
    }

3. if-else if-else if...
Використовується, коли необхідно перевірити декілька умов і вибрати відповідний варіант виконання.
Приклад: визначення оцінки за кількістю балів.

    int score = 85;
    
    if (score >= 90) {
    System.out.println("Відмінно");
    } else if (score >= 75) {
    System.out.println("Добре");
    } else if (score >= 60) {
    System.out.println("Задовільно");
    } else {
    System.out.println("Незадовільно");
    }

4. switch
Використовується, коли потрібно вибрати один із декількох варіантів залежно від значення певної змінної або виразу.
Приклад: вибір дня тижня за номером.

    int day = 3;
    
    switch (day) {
    case 1:
    System.out.println("Понеділок");
    break;
    case 2:
    System.out.println("Вівторок");
    break;
    case 3:
    System.out.println("Середа");
    break;
    default:
    System.out.println("Невідомий день");
    }

5. умовна операція ?:
Використовується для короткого запису умовного виразу, який повертає одне з двох значень залежно від умови.
Приклад: визначення більшого числа.

    int a = 10;
    int b = 20;
    
    int max = (a > b) ? a : b;
    
    System.out.println(max);

## 10. Наведіть приклади, у яких випадках краще використовувати наступні оператори та конструкції.

1. while
Використовується, коли кількість повторень заздалегідь невідома, а виконання циклу залежить від певної умови. Умова перевіряється перед кожною ітерацією.
Приклад: виведення чисел від 1 до 5.

    int i = 1;
    
    while (i <= 5) {
    System.out.println(i);
    i++;
    }

2. do-while
Використовується, коли потрібно, щоб тіло циклу виконалося хоча б один раз незалежно від початкового значення умови. Умова перевіряється після виконання тіла циклу.
Приклад: запит введення числа з клавіатури хоча б один раз.

    int number = 0;
    
    do {
    System.out.println("Введіть число більше 0");
    number++;
    } while (number <= 0);

3. for
Використовується, коли кількість повторень циклу відома заздалегідь. Ініціалізація, умова продовження та зміна лічильника записуються в одному рядку.
Приклад: обчислення суми чисел від 1 до 10.

    int sum = 0;
    
    for (int i = 1; i <= 10; i++) {
    sum += i;
    }
    
    System.out.println(sum);

## 11. Чим оператор break відрізняється від оператора continue?

Оператори break і continue використовуються для керування виконанням циклів, але виконують різні функції.
- break - повністю припиняє виконання найближчого циклу або конструкції switch і передає керування команді, яка розташована після нього.
- continue - припиняє виконання поточної ітерації циклу та переходить до наступної ітерації.

## 12. Навіщо у мові Java є мітки, якщо немає goto?

У Java мітки використовуються для позначення певних циклів або блоків коду. 
Вони дозволяють операторам break і continue звертатися до конкретного зовнішнього циклу, а не лише до найближчого. 
Мітки дозволяють керувати вкладеними циклами без використання оператора goto.

## 13. До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.

    boolean a = false;
    boolean b = false;
    
    if (a = false) {
    System.out.println("a is false");
    }
    
    if (b = true) {
    System.out.println("b is true");
    }
    
    if (a = b) {
    System.out.println("a = b");
    }

Пояснення:
1. if (a = false) - змінній a присвоюється значення false. Умова хибна, тому повідомлення не виводиться.
2. if (b = true) - змінній b присвоюється значення true. Умова істинна, тому виводиться b is true.
3. if (a = b) - змінній a присвоюється значення b, тобто true. Умова істинна, тому виводиться a = b.

Результат:

    b is true
    a = b

## 14. До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.

    int a = 1;
    a++;
    ++a;
    
    switch(a) {
    case 1: System.out.println("1");
    case 2: System.out.println("2");
    case 3: System.out.println("3");
    case 4: System.out.println("4");
    }

Оператори a++ та ++a збільшують значення змінної на одиницю.
Якщо в конструкції switch відсутній break, виконання продовжується в наступних case (fall-through).

Пояснення:
1. Спочатку a = 1.
2. Після a++ значення a збільшується до 2.
3. Після ++a значення a збільшується до 3.
4. Оператор switch отримує значення 3 і переходить до case 3.
5. Оскільки оператори break відсутні, виконуються також усі наступні гілки case.

Результат:

    3
    4

## 15. До якого результату призведе виконання наступного фрагменту коду (true/false)? Перевірте. Поясніть.

    double sum = 0;
    
    // Let's find: 1 + 1/2 + 1/3 + 1/4 + 1/5 + ...
    for(int i = 1; i < 10; i++) {
    sum = sum + 1/i;
    }
    
    System.out.println(sum > 1);


Пояснення:
Цикл for виконується для значень i від 1 до 9.
Однак у виразі 1/i обидва операнди мають тип int, тому Java виконує цілочисельне ділення, відкидаючи дробову частину.

|Вираз|Результат|
|---|---|
|1/1|1|
|1/2|0|
|1/3|0|
|1/4|0|
|1/5|0|
|1/6|0|
|1/7|0|
|1/8|0|
|1/9|0|
|1/10|0|

Результат:

    false
