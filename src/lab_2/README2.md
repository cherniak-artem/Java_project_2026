# Контрольні питання

## 1. В чому полягає різниця між ключовими та зарезервованими словами?

Ключові слова (keywords) - це слова, які мають спеціальне призначення в мові програмування Java та використовуються для побудови програмного коду.

Приклади: int, class, if, else, while, return, public, static.

Зарезервовані слова (reserved words) - це слова, які зарезервовані мовою програмування і не можуть використовуватися як ідентифікатори (назви змінних, методів, класів тощо).

##  2. Які примітивні типи даних Ви знаєте? Для кожного з них наведіть приклади, коли найбільш ефективно використовувати саме цей тип (наприклад: довжина файлу, кількість зірок на небі, рахунок у футбольному матчі, маса всесвіту, заробітна платня, ...).

У Java існує 8 примітивних типів даних.
Вони поділяються на цілочисельні, символьний та типи з рухомою комою.

|Тип|Розмір|Діапазон значень|Приклад використання|
|---|---|---|---|
|byte|8 біт|-128 ... 127|Невеликі числові значення, наприклад температура|
|short|16 біт|-32 768 ... 32 767|Кількість учнів у великих навчальних закладах|
|int|32 біти|-2 147 483 648 ... 2 147 483 647|Кількість зірок у певному каталозі, рахунок у футбольному матчі|
|long|64 біти|приблизно 9,22 × 10^18|Розмір великих файлів у байтах, кількість населення|
|float|32 біти|приблизно 7 значущих десяткових цифр|Вимірювання температури, наближені фізичні розрахунки|
|double|64 біти|приблизно 15–16 значущих десяткових цифр|Наукові обчислення, фізичні величини|
|char|16 біт|0 ... 65 535|Зберігання одного символу, наприклад 'A'|
|boolean|JVM-залежний|true або false|Перевірка умов, стан кнопки, наявність помилки|

## 3. Що таке знакові та беззнакові типи? До якої групи відноситься кожен із примітивних типів даних?

Знакові типи - це типи даних, які можуть зберігати як додатні, так і від'ємні числа, а також нуль.

Беззнакові типи - це типи, які можуть зберігати тільки невід'ємні числа, тобто нуль та додатні значення.

У Java розподіл такий:
- byte — знаковий.
- short — знаковий.
- int — знаковий.
- long — знаковий.
- float — знаковий.
- double — знаковий.
- char — беззнаковий.
- boolean — не належить до знакових або беззнакових числових типів.

## 5. Змінна типу byte може приймати значення у діапазоні -128..127. Чому цей діапазон саме такий? Чому від'ємних значень більше ніж додатних?

Оскільки один біт використовується в межах двійкового представлення числа зі знаком, кількість можливих комбінацій становить: 2<sup>8</sup> = 256

Для представлення від'ємних та додатних чисел Java використовує доповняльний код.
Діапазон значень визначається формулою:
-2<sup>7</sup> < x < 2<sup>7</sup>-1  
Отже: -128 < x < 127

Одним з додатніх значень виступає "0"

## 6. Що таке система числення? Як переводити значення з однієї системи числення в іншу?

Система числення - це спосіб запису чисел за допомогою певного набору символів (цифр) та правил їх використання.

Найпоширеніші системи числення:
- Десяткова (основа 10): цифри від 0 до 9.
- Двійкова (основа 2): цифри 0 та 1.
- Вісімкова (основа 8): цифри від 0 до 7.
- Шістнадцяткова (основа 16): цифри від 0 до 9 та літери A–F.

Переведення з десяткової системи в двійкову.

Для переведення цілого числа потрібно послідовно ділити його на 2 та записувати остачі. Результат читається знизу вгору.

Переведення з двійкової системи в десяткову.

Кожну цифру множимо на відповідний степінь числа 2

Той самий принцип використовується для переведення з/в вісімкову, двійкову системи

## 7. Що таке «Доповняльний код»?

Доповняльний код - це спосіб представлення від'ємних цілих чисел у двійковій системі числення.

У Java він використовується для представлення знакових цілочисельних типів (byte, short, int, long).

Щоб отримати доповняльний код від'ємного числа, необхідно:

1. Записати додатне число у двійковій системі.
2. Інвертувати всі біти (0 замінити на 1, а 1 на 0).
3. Додати одиницю до отриманого результату.

## 8. Пояснити результат роботи такого фрагмента коду:

    int a = 2_000_000_000;
    int b = 2_000_000_000;
    int c = a + b;

    System.out.println(c);

Тип int має діапазон від -2 147 483 648 до 2 147 483 647.

Після додавання отримуємо: 2 000 000 000 + 2 000 000 000 = 4 000 000 000

Це число перевищує максимальне значення типу int.

У Java при переповненні цілочисельного типу відбувається циклічний перехід через межі діапазону (без автоматичного повідомлення про помилку).

Результат: 
    
    -294967296

Щоб уникнути переповнення, потрібно використовувати тип long:

    long a = 2_000_000_000L;
    long b = 2_000_000_000L;
    long c = a + b;

    System.out.println(c);

Результат:

    4000000000

## 9. Чим тип float відрізняється від double?

Обидва типи використовуються для зберігання чисел із рухомою комою, але відрізняються розміром пам'яті та точністю.

|Характеристики|float|double|
|---|---|---|
|Розмір|32 біти|64 біти|
|Точність|7 цифр після коми|15–16 цифр після коми|
|Суфікс числа|f або F|необов'язковий|

## 10. Що таке число з рухомою комою? Що таке мантиса та степінь?

Число з рухомою комою - це спосіб представлення дійсних чисел, який дозволяє зберігати дуже великі та дуже малі значення.

Таке число можна представити у вигляді: N = (-1)<sup>s</sup> x M x 2<sup>E</sup>

- s - біт знака (0 - додатне число, 1 - від'ємне).
- M - мантиса, яка визначає значущі цифри числа.
- E - степінь (порядок), який визначає масштаб числа.


## 11. Що таке Double.NaN?

Double.NaN (Not a Number) - це спеціальне значення типу double, яке означає, що результат математичної операції не є визначеним числом.

## 12. Пояснити результат роботи такого фрагменту коду:

    System.out.println(Double.NaN == Double.NaN);

Результат виконання:

    false

Це пояснюється тим, що згідно зі стандартом IEEE 754 значення NaN не дорівнює жодному значенню, включаючи саме себе.

Для перевірки необхідно використовувати метод:

    Double.isNaN(Double.NaN);

Результат:

    true

## 13. Пояснити різницю між преінкрементом та постінкрементом. Навести приклади, коли ці операції призводять до різних результатів.

Інкремент - це операція збільшення значення змінної на одиницю.

У Java існує два види інкременту:
- Преінкремент (++a) - спочатку збільшує значення змінної на одиницю, а потім повертає нове значення.
- Постінкремент (a++) - спочатку повертає поточне значення змінної, а потім збільшує її на одиницю.

## 14. У чому різниця між логічною та побітовою операцією AND? Чому звичайна операція AND (&) є в обох варіантах, а її короткозамкнута версія (&&) лише логічна?

Операція AND (І) використовується для перевірки того, чи обидва операнди мають значення true або містять одиничні біти.

Логічна операція AND (&&) працює з логічними значеннями true та false.

Вона використовує коротке замикання: якщо перший операнд дорівнює false, другий операнд не перевіряється, оскільки результат у будь-якому випадку буде false.

## 15. У чому різниця між OR та XOR?

OR (логічне АБО) — операція, яка повертає true, якщо хоча б один із двох операндів має значення true.

XOR (виключне АБО) — операція, яка повертає true лише тоді, коли значення операндів відрізняються.

## 16. Проаналізувати наступний фрагмент програми. Передбачити його результат. Запустити. Пояснити.

    boolean a = true && false | false;
    System.out.println(a = false);

    boolean b = true && false || false;
    System.out.println(b = true);

Перший вираз:

    boolean a = true && false | false;

У Java оператори мають різний пріоритет.

У цьому випадку оператор & та | мають вищий пріоритет, ніж &&, але | не є тотожним ||.

Оскільки вираз має вигляд true && false | false, спочатку виконується побітове (логічне для boolean) OR:

    false | false

Результат - false.

Далі виконується:

    true && false

Результат — false.

Наступний рядок:

    System.out.println(a = false);

не просто виводить значення змінної, а спочатку присвоює їй false, а потім виводить результат присвоєння.

Другий вираз:

    boolean b = true && false || false;

Оператор && має вищий пріоритет, ніж ||

Тому спочатку виконується: 

    true && false

Результат — false.

Далі виконується:

    false || false

Результат — false.

Наступний рядок:

    System.out.println(b = true);

Присвоює змінній b значення true та виводить його

Результат: true

Результат виконання коду:

    false
    true
