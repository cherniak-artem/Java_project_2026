# Контрольні питання

## 1. Чим змінна відрізняється від масиву?

Змінна - це іменована область пам'яті, призначена для зберігання одного значення певного типу даних.

Масив - це структура даних, яка дозволяє зберігати декілька значень одного типу під одним ім'ям. Доступ до кожного елемента здійснюється за його індексом.

##  2. Що таке стек? Що таке купа? Яка між ними різниця?

Стек (Stack) - це область пам'яті, у якій зберігаються локальні змінні та службова інформація про виклики методів. 
Пам'ять у стеку виділяється та звільняється автоматично під час виклику й завершення методів.

Купа (Heap) - це область пам'яті, у якій зберігаються об'єкти та масиви, створені під час виконання програми за допомогою оператора new.

Різниця в тому, що стек використовується для організації викликів методів і зберігання локальних змінних, а купа - для зберігання об'єктів і масивів. 
Пам'ять у купі звільняється автоматично "збирачем сміття" (Garbage Collector), коли об'єкти стають недоступними.

##  3. Чи може змінна бути розташована у стеку? Безпосередньо у купі? В об'єкті у купі? Чи може масив бути розташований у стеку? Безпосередньо у купі? В об'єкті у купі?

- Змінна може бути розташована у стеку, якщо це локальна змінна методу.
- Безпосередньо у купі змінна зазвичай не розташовується як окрема локальна змінна.
- Змінна може бути полем об'єкта, який розташований у купі.
- Масив не розташовується у стеку як окремий об'єкт, оскільки створюється у купі.
- Масив може бути безпосередньо розташований у купі.
- Масив також може бути полем об'єкта, який розташований у купі.

## 4. Чим посилання на масив відрізняється від масиву? Чи може посилання на масив бути розташовано у стеку? Безпосередньо у купі? В об'єкті у купі?

Масив - це об'єкт, який містить набір елементів одного типу. 
Посилання на масив - це змінна, яка зберігає адресу (точніше, посилання) на цей об'єкт.

Посилання на масив може розташовуватися:
- У стеку — якщо це локальна змінна методу.
- У купі як поле іншого об'єкта.
- У масиві посилань, який сам розташований у купі. Сам масив при цьому залишається окремим об'єктом у купі.

## 5. Якщо масив складається з 10 комірок, які індекси мають перша та остання комірки?

У Java індексація масивів починається з нуля. Перша комірка має індекс 0, а остання - індекс 9.

## 6. Що буде, якщо звернутися до неіснуючої комірки у масиві?

Якщо звернутися до елемента масиву за індексом, який виходить за межі його розміру, Java згенерує виняток ArrayIndexOutOfBoundsException.

    int[] numbers = new int[10];
    System.out.println(numbers[10]);

Виникне помилка, оскільки допустимі індекси - від 0 до 9.

## 7. При створенні нового масиву без явної ініціалізації усі його комірки будуть проініціалізовані: спеціальними значеннями за замовчуванням чи довільними значеннями, що знаходяться в цей час у пам'яті?

Усі комірки масиву в Java автоматично ініціалізуються значеннями за замовчуванням відповідно до типу даних:
- int, long, short, byte - 0;
- float, double - 0.0;
- boolean - false;
- char - '\u0000';
- посилальні типи - null.
 
Масив не містить довільних значень із пам'яті.

## 8. Як дізнатися номер першої та останньої комірки масиву, якщо відомо лише посилання на нього?

У Java перший індекс масиву завжди дорівнює 0, а останній визначається за допомогою властивості length.

    int[] numbers = new int[10];
    
    int first = 0;
    int last = numbers.length - 1;

## 9. Як змінити розмір масиву?

У Java розмір масиву після створення змінити неможливо. 
Якщо потрібно отримати масив іншого розміру, необхідно створити новий масив і скопіювати до нього потрібні елементи зі старого.
Для цього можна використовувати метод Arrays.copyOf().

    import java.util.Arrays;
    
    int[] numbers = {1, 2, 3};
    numbers = Arrays.copyOf(numbers, 5);

У результаті буде створено новий масив із п'яти елементів. 
Перші три елементи збережуть свої значення, а два нові отримають значення 0.

## 10. Що відбувається з масивом при копіюванні посилання на нього?

При копіюванні посилання створюється ще одна змінна, яка вказує на той самий масив. Сам масив не копіюється.

## 11. Що відбувається з масивом при втрачанні посилання на нього?

Якщо на масив більше не існує жодного доступного посилання, він стає недоступним для програми та може бути видалений "збирачем сміття" (Garbage Collector).
Пам'ять, яку займав масив, згодом звільняється автоматично. Саме видалення не обов'язково відбувається одразу після втрати посилання.

## 12. Чим відрізняються конструкції for та for-each при роботі з масивами? Які переваги та недоліки кожного з варіантів?

for - це звичайний цикл, у якому програміст самостійно задає початкове значення лічильника, умову завершення та крок його зміни.

    int[] numbers = {10, 20, 30};
    
    for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
    }

Переваги:
- Можна отримати доступ до індексу кожного елемента.
- Можна змінювати елементи масиву.
- Можна перебирати масив у зворотному порядку.
- Можна пропускати окремі елементи.
  
Недоліки:
- Потрібно самостійно контролювати індекси.

for-each - це цикл, який автоматично перебирає всі елементи масиву без необхідності використовувати індекси.

    int[] numbers = {10, 20, 30};
    
    for (int number : numbers) {
    System.out.println(number);
    }

Переваги:
- Простий і зручний запис.
- Не потрібно самостійно контролювати індекси.
- Менший ризик помилок під час перебору.

Недоліки:
- Не можна отримати індекс елемента.
- Незручно перебирати масив у зворотному порядку.
- Не можна змінити елементи масиву через локальну змінну циклу, якщо це примітивні типи.

## 13. Чи можна у масив double[] записати значення int? Чи можна у масив int[] записати значення double?

У масив типу double[] можна записувати значення типу int, оскільки Java автоматично перетворює ціле число на число з плаваючою комою (розширювальне перетворення типів).

У масив типу int[] не можна безпосередньо записати значення типу double, оскільки це може призвести до втрати дробової частини числа.
