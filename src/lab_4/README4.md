# Контрольні питання

## 1. Порівняйте та назвіть переваги та недоліки таких методів сортування: сортування бульбашкою, сортування вибором, сортування вставкою.

Сортування бульбашкою (Bubble Sort) - алгоритм, який послідовно порівнює сусідні елементи масиву та міняє їх місцями, якщо вони розташовані в неправильному порядку. 
Після кожного проходу найбільший елемент переміщується в кінець масиву.
- Переваги: простий у реалізації та розумінні; не потребує додаткової пам'яті; добре працює з невеликими або майже відсортованими масивами за наявності перевірки обмінів.
- Недоліки: низька швидкодія на великих масивах; виконує багато порівнянь та обмінів елементів.

Сортування вибором (Selection Sort) - алгоритм, який на кожному кроці знаходить найменший елемент у невідсортованій частині масиву та міняє його місцями з першим елементом цієї частини.
- Переваги: простий у реалізації; потребує мінімальної додаткової пам'яті; виконує невелику кількість обмінів елементів.
- Недоліки: завжди виконує приблизно однакову кількість порівнянь незалежно від початкового порядку елементів; неефективний для великих масивів; за стандартної реалізації не є стабільним.

Сортування вставкою (Insertion Sort) - алгоритм, який послідовно бере елементи масиву та вставляє кожен із них у правильне місце серед уже відсортованих елементів.
- Переваги: простий у реалізації; ефективний для невеликих і майже відсортованих масивів; потребує мінімальної додаткової пам'яті; є стабільним.
- Недоліки: повільний для великих масивів, особливо якщо вони відсортовані у зворотному порядку; може виконувати багато переміщень елементів.

## 2. Оцініть кожен з методів відповідно до наступних критеріїв: час роботи, потреби у додатковій пам'яті, стабільність. За якими ще критеріями ви можете порівняти ці алгоритми?

Основні характеристики алгоритмів:

|Критерій|Бульбашкою|Вибором|Вставкою|
|---|---|---|---|
|Найкращий час роботи|O(n)|O(n<sup>2</sup>)|O(n)|
|Середній час роботи|O(n<sup>2</sup>|O(n<sup>2</sup>|O(n<sup>2</sup>|
|Найгірший час роботи|O(n<sup>2</sup>|O(n<sup>2</sup>|O(n<sup>2</sup>|
|Додаткова пам'ять|O(1)|O(1)|O(1)|
|Стабільність|+|-|+|

Стабільність - це властивість алгоритму зберігати початковий взаємний порядок елементів з однаковими значеннями.

Додатково алгоритми можна порівнювати за такими критеріями:
- Кількість порівнянь - скільки разів алгоритм порівнює елементи між собою.
- Кількість обмінів і переміщень - скільки разів елементи змінюють своє положення.
- Адаптивність - наскільки алгоритм ефективно використовує той факт, що масив уже частково відсортований.
- Простота реалізації - наскільки легко зрозуміти та написати алгоритм.

## 3. Який випадок є найкращим або найгіршим для роботи цих алгоритмів? Який метод забезпечить найкращий/найгірший результат?
   Для кожного алгоритму ефективність залежить від початкового порядку елементів масиву.

Сортування бульбашкою:
- Найкращий випадок - масив уже відсортований за зростанням. Час роботи O(n), якщо використовується перевірка обмінів.
- Найгірший випадок - масив відсортований у зворотному порядку. Час роботи O(n<sup>2</sup>).

Сортування вибором:
- Найкращий випадок - масив уже відсортований. Проте алгоритм усе одно виконує O(n<sup>2</sup>) порівнянь.
- Найгірший випадок - масив відсортований у зворотному порядку. Час роботи також O(n<sup>2</sup>).
Особливість цього алгоритму полягає в тому, що кількість порівнянь практично не залежить від початкового порядку елементів.

Сортування вставкою:
- Найкращий випадок — масив уже відсортований або майже відсортований. Час роботи O(n).
- Найгірший випадок — масив відсортований у зворотному порядку. Час роботи O(n<sup>2</sup>).

## 4. Що означають позначення O(1), O(n), O(n²)?

Ці позначення називаються O-нотацією (Big O) і використовуються для оцінювання складності алгоритмів. 
Вони показують, як змінюється час виконання або обсяг пам'яті залежно від розміру вхідних даних.

- O(1) - константна складність. Час виконання не залежить від кількості елементів. 
Наприклад, отримання елемента масиву за індексом.
- O(n) - лінійна складність. Час виконання зростає пропорційно кількості елементів. 
Наприклад, послідовний перегляд усіх елементів масиву.
- O(n²) - квадратична складність. Час виконання зростає приблизно пропорційно квадрату кількості елементів. 
Наприклад, порівняння кожного елемента масиву з іншими елементами за допомогою двох вкладених циклів.
