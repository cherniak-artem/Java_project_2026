# Контрольні питання

## 1. Що таке immutable об’єкт? Для чого об’єкти класу String зробили імутабельними? Чому клас String задекларований як final?

Immutable - це об’єкт, стан якого неможливо змінити після його створення.

Об’єкти класу String зробили імутабельними з кількох причин:
- Безпека - неможливо непомітно змінити рядок, який використовується для зберігання паролів, шляхів або інших важливих даних.
- Надійність - значення рядка залишається незмінним протягом роботи програми.
- Ефективність - рядки можна безпечно використовувати повторно, наприклад через String Pool.
  
Клас String оголошений як final, щоб заборонити створення класів-нащадків і перевизначення його поведінки. Це допомагає зберігати незмінність та безпеку роботи з рядками.

## 2. Що таке регулярні вирази? Наведіть приклади регулярних виразів.

Регулярні вирази (Regular Expressions) - це спеціальні шаблони, 
які використовуються для пошуку, перевірки та обробки тексту відповідно до заданих умов.

|Регулярний вираз|Призначення|
|---|---|
|[0-9]+|Одна або більше цифр|
|[a-zA-Z]+|Одна або більше англійських літер|
|[a-zA-Z0-9]+|Літери та цифри|
|\d{4}|Рівно чотири цифри|
|\s+|Один або більше пробільних символів|
|[^0-9]+|Один або більше символів, крім цифр|

## 3. В чому полягає різниця між оператором «==» та методом «equals()»?

Основна різниця полягає в тому, що:
- == порівнює посилання на об'єкти, тобто перевіряє, чи посилаються дві змінні на один і той самий об'єкт.
- equals() порівнює вміст об'єктів, тобто перевіряє, чи однакові їхні значення.

## 4. Для чого потрібні класи StringBuilder та StringBuffer?

StringBuilder та StringBuffer використовуються для створення та зміни рядків без необхідності постійно створювати нові об'єкти, 
як це відбувається з класом String.

Основні відмінності:
- StringBuilder — дозволяє швидко змінювати рядки, але не є потокобезпечним.
- StringBuffer — має схожі можливості, але його методи синхронізовані, тому він безпечніший при одночасній роботі декількох потоків.

## 5. Яким чином простіше всього прибрати пробіли на початку та кінці об’єкту String?

Найпростіший спосіб - використати метод trim() класу String.

Метод trim() видаляє пробільні символи на початку та в кінці рядка, але не змінює пробіли між словами.
