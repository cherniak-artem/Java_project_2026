# Контрольні питання

## 1. Для чого призначений Collections Framework?

Java Collections Framework - це набір інтерфейсів і класів, призначений для зберігання, організації та обробки груп об'єктів.

Він надає готові структури даних, за допомогою яких можна додавати, видаляти, шукати та переглядати елементи. 
Наприклад, List, ArrayList, LinkedList та Iterator.

## 2. В чому полягає різниця між масивами та колекціями?

Основна різниця полягає в можливостях зміни розміру та способах роботи з даними.
- Масиви мають фіксований розмір, який визначається під час створення. Для роботи з ними використовуються індекси.
- Колекції зазвичай мають динамічний розмір, тобто можуть автоматично збільшуватися або зменшуватися під час додавання чи видалення елементів.
Також колекції надають більше готових методів для роботи з даними, наприклад пошуку, сортування та видалення елементів.

## 3. Які особливі властивості є у списків порівняно з іншими типами колекцій?

- Зберігають порядок додавання елементів.
- Дозволяють зберігати однакові елементи.
- Дозволяють звертатися до елементів за індексом.
- Підтримують додавання, видалення та зміну елементів у певній позиції.

## 4. Чим списки відрізняються від масивів?

- Масиви мають фіксований розмір, а списки можуть динамічно змінювати його.
- Масиви можуть зберігати примітивні типи даних (int, double тощо), а типізовані списки зберігають об'єкти (для чисел використовуються класи-обгортки, наприклад Integer).
- Списки мають готові методи для додавання, видалення та пошуку елементів.
- Для списків доступні різні реалізації, наприклад ArrayList та LinkedList.

## 5. Чим ArrayList відрізняється від LinkedList? Який з них у яких випадках краще використовувати?

ArrayList:
- Побудований на основі динамічного масиву.
- Забезпечує швидкий доступ до елементів за індексом.
- Додавання елементів у середину може вимагати переміщення інших елементів.

LinkedList:
- Побудований на основі двозв'язного списку.
- Елементи пов'язані між собою посиланнями.
- Забезпечує зручне додавання та видалення елементів на початку й наприкінці списку.
- Повільніше отримує елементи за індексом.

Коли використовується:
- ArrayList - коли необхідно часто переглядати елементи та звертатися до них за індексом.
- LinkedList - коли часто потрібно додавати або видаляти елементи на початку чи наприкінці списку.

## 6. Що таке Iterator? В чому полягають переваги використання ітератора у порівнянні з класичним циклом for?

Iterator - це інтерфейс Java, який дозволяє послідовно переглядати елементи колекції без необхідності звертатися до них за індексом.

Основні методи:
- hasNext() — перевіряє наявність наступного елемента.
- next() — повертає наступний елемент.
- remove() — видаляє поточний елемент із колекції, якщо операція підтримується.

Переваги ітератора:
- Дозволяє працювати з різними типами колекцій без використання індексів.
- Підходить для ArrayList, LinkedList та інших колекцій.
- Дозволяє безпечно видаляти елементи під час обходу за допомогою remove().
- Не потребує постійного звернення до розміру колекції через size().

## 7. Що таке типізовані та нетипізовані колекції?

Типізовані колекції - це колекції, для яких заздалегідь визначено тип об'єктів, які вони можуть зберігати.

Нетипізовані колекції - це колекції, для яких тип елементів не визначений під час оголошення.

## 8. Для чого потрібен інтерфейс RandomAccess?

RandomAccess - це маркерний інтерфейс, який позначає списки, що підтримують швидкий довільний доступ до елементів за індексом.

Він не містить власних методів, а лише повідомляє програмі про особливості реалізації списку.

## 9. Чим Collection відрізняється від Collections?

Collection - це базовий інтерфейс Java Collections Framework, 
який визначає основні операції для роботи з групами об'єктів: додавання, видалення, пошук та перегляд елементів.

Collections — це службовий клас із набором статичних методів для роботи з колекціями.

Функціонал:
- Collections.sort() — сортувати список.
- Collections.reverse() — змінювати порядок елементів на зворотний.
- Collections.shuffle() — перемішувати елементи.
- Collections.max() — знаходити найбільший елемент.
- Collections.min() — знаходити найменший елемент.
